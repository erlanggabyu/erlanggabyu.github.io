01

Peran
Modifikasi tampilan display & aplikasi pendamping (AI-assisted)
Konteks
Usaha keluarga · modul klakson telolet "BKH"
Periode
2023 sampai sekarang
Alat
ESP32, C++ (Arduino), LVGL, TFT 320×240, Flutter, Bluetooth, WiFi, Claude Code

Memberi wajah baru untuk modul klakson telolet.

Modul klakson berbasis ESP32 ini memakai program yang dibeli jadi, tetapi tampilan layarnya terlihat kuno. Saya ditugaskan memodifikasi tampilan agar lebih modern tanpa merusak fungsi alat.

Yang saya kerjakan

  • Mempelajari kode program ESP32 yang sudah ada (±2.900 baris) untuk memahami alur tampilan, pemutar MIDI, dan tombol.
  • Merancang ulang tampilan layar TFT 320×240 dengan LVGL: animasi pembuka yang diputar dari SD card dan layar utama "Neon Equalizer" yang bergerak mengikuti nada.
  • Mendokumentasikan protokol Bluetooth dan API WiFi alat menjadi spesifikasi aplikasi, termasuk bug pada fitur upload yang bisa membuat ESP32 crash.
  • Membangun aplikasi Android (Flutter) pendamping: kelola lagu via WiFi, remote via Bluetooth, dan pad klakson. Saat ini dalam tahap uji dengan alat.

Perangkat keras dan PCB dirancang serta dirakit oleh pemilik usaha menggunakan KiCad; saya fokus pada perangkat lunak tampilan dan aplikasi.

02

Peran
Volunteer Divisi Running Event
Acara
Comafest
Lokasi
Plaza Parkir Timur GBK, Jakarta
Periode
25 sampai 28 Juni 2026 · 4 hari
Alat
HT (handy talky), rundown, cue sheet

Menjaga konser tetap berjalan sesuai rundown.

Comafest berlangsung empat hari di Plaza Parkir Timur GBK dengan sekitar 10 ribu pengunjung, sehingga setiap menit di balik panggung harus terkoordinasi. Sebagai volunteer divisi running event, saya membantu memastikan acara berjalan tepat waktu dari persiapan hingga selesai.

Yang saya kerjakan

  • Mengikuti briefing dan gladi untuk memahami rundown serta urutan penampil.
  • Memantau jalannya acara sesuai rundown dan memberi aba-aba (cue) ke penampil dan tim terkait.
  • Berkoordinasi lewat HT dengan stage manager, divisi produksi, dan divisi lain saat ada perubahan jadwal.
  • Membantu menangani kendala di lapangan dengan cepat agar acara tetap berjalan.

03

Peran
Analis Sistem & Developer (AI-assisted)
Konteks
Proyek mata kuliah · Semester 2
Periode
Mei sampai Jul 2026
Alat
PHP, Laravel 13, MySQL, Bootstrap 5, PHPUnit, GitHub

Mendigitalkan pendaftaran umroh dari paket sampai invoice.

Khaybar Tour adalah sistem pendaftaran umroh berbasis web. Pelanggan bisa memilih paket, mengisi data jamaah, mengunggah dokumen dan bukti pembayaran, lalu mencetak invoice. Admin memverifikasi semuanya dari satu dashboard.

Yang saya kerjakan

  • Memodelkan alur bisnis lewat rich picture, UML, dan mockup UI sebelum mulai membangun.
  • Membangun aplikasi Laravel dengan bantuan AI (vibe coding), lalu meninjau dan memperbaiki hasilnya.
  • Menyusun akses berbasis role (Admin & Pelanggan) serta alur pembayaran DP, pelunasan, dan cicilan.
  • Menguji fitur utama dengan feature test PHPUnit dan menambahkan pengamanan upload file serta login.
